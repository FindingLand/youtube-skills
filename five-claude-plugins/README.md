# 5 Claude plugins every automation builder needs

From my YouTube Short. All five are free to install, all open source (MIT or Apache-2.0). Stars and licenses checked Nov 17 2026.

| # | Plugin | What it does | Install in Claude Code |
|---|---|---|---|
| 1 | [n8n Skills](https://github.com/czlonkowski/n8n-skills) | Teaches Claude to build and validate n8n workflows node by node. Needs the free [n8n-mcp](https://github.com/czlonkowski/n8n-mcp) server | `/plugin install czlonkowski/n8n-skills` |
| 2 | [Playwright](https://github.com/microsoft/playwright-mcp) (Microsoft) | Claude opens a real browser, clicks, fills forms and reads pages | `/plugin install playwright@claude-plugins-official` |
| 3 | [Context7](https://github.com/upstash/context7) | Pulls the current docs of your tools into Claude, so it stops writing code for old versions. Hosted server: free key for higher limits, paid plans above that | `/plugin install context7@claude-plugins-official` |
| 4 | [Superpowers](https://github.com/obra/superpowers) | Brainstorm, plan, build with review, test before it says done | `/plugin install superpowers@claude-plugins-official` |
| 5 | [Skill Creator](https://github.com/anthropics/claude-plugins-official/tree/main/plugins/skill-creator) (Anthropic) | Describe a process once, it writes a skill Claude follows every time | `/plugin install skill-creator@claude-plugins-official` |

Each plugin belongs to its authors under its own license. This page only links to them.
