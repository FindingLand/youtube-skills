# YouTube skills

Free Claude Code skills and plugins from my YouTube Shorts. One folder per video, ready to install.

I'm Peter Israel, I build AI automations for businesses. Channel: [@PeterIsraelAI](https://www.youtube.com/@PeterIsraelAI)

| Video | Folder | What it does |
|---|---|---|
| Google's free fix for sloppy AI code | [elephant-goldfish-model](elephant-goldfish-model) | An "elephant" agent that knows your project writes the plan, then "goldfish" agents with zero memory of your chat try to break it before any code is written |

## Install in Claude Code

```
/plugin marketplace add FindingLand/youtube-skills
/plugin install egm@youtube-skills
```

Then run `/egm:egm-brainstorm` with your idea, and `/egm:egm-review` on the plan before you let Claude code it.
