# 283 free AI specialists inside Claude Code: Agency Agents

From my YouTube Short. Repo: [msitarzewski/agency-agents](https://github.com/msitarzewski/agency-agents) (MIT, checked Nov 17 2026): 283 agents in 18 divisions.

## Install

```
git clone https://github.com/msitarzewski/agency-agents.git
cd agency-agents
./scripts/install.sh --tool claude-code
```

This copies the agents into `~/.claude/agents/`. On Windows run it from Git Bash or WSL. Then ask Claude for any agent by name.

## The three a small business would use first

| Agent | Job |
|---|---|
| Outbound Strategist | Picks who to target and plans your cold email sequence |
| Proposal Strategist | Turns a sales call into a written proposal |
| Customer Service | Handles questions and complaints, and knows when to pass it to a human |

The agents are free. Claude Code itself needs a paid Claude plan.
